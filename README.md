# Learning Hub

Installable, offline learning apps in one menu.

- `index.html`: the menu
- `kannada/`: Kannada in 90 Days
- `react/`: React for ServiceNow (6-week plan)
- `ai/`: ServiceNow AI for Developers (8 hands-on labs)
- `sw.js`: offline cache. Bump `VERSION` on every change so phones pick up the update.
